Especificações da Plataforma

EKARCHVIZ — Spatial 360° Engine (Desktop & Mobile) combina design editorial internacional com navegação tridimensional ultra-rápida.

• Gestos Mobile & Sensor Giroscópio: No celular, deslize com 1 dedo para girar, faça pinça com 2 dedos para dar zoom ou ative o Sensor para mover o celular no espaço.
• Bolinhas 3D Touch: Toque para mudar de ambiente ou segure pressionado por 0.6s para remover uma conexão.
• Links Ultra-Curtos: Ao tocar em Partilhar, o sistema gera um link compacto que abre direto na tela do cliente.
